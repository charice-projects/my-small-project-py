
# Excel 转 vCard 通讯录转换器 v3.1

将 Excel 表格中的联系人一键转换为手机通讯录可识别的 `.vcf` 文件。  
解决因一个单元格包含多个电话/邮箱导致导入失败的问题，并智能处理 Windows 复制路径时夹带的不可见字符。

## 📦 依赖安装

```bash
pip install pandas openpyxl
```

> 若需读取旧版 `.xls` 文件，请额外安装 `xlrd`：`pip install xlrd`

## 🚀 快速开始

### 1. 交互模式（推荐）

```bash
python excel-to-vcf.py
```

根据提示输入 Excel 文件路径（支持拖拽文件到窗口），程序会自动检测列名并生成 VCF 文件。

### 2. 命令行模式（适合批量处理）

```bash
python excel-to-vcf.py -i "C:/联系人.xlsx" -o output.vcf -b 200
```

### 3. 作为 Python 模块调用

```python
from excel_to_vcf import quick_convert

quick_convert("联系人.xlsx", batch_size=300, debug=True)
```

## 📄 参数说明

| 参数 | 说明 |
|------|------|
| `-i, --input` | 输入 Excel 文件路径（必填） |
| `-o, --output` | 输出 VCF 文件路径（可选，默认与 Excel 同目录） |
| `-s, --sheet` | 工作表名或索引（默认第一个工作表） |
| `-b, --batch` | 每批记录数，0 表示不分批（例如 200） |
| `-d, --debug` | 开启调试模式，显示路径清洗前后的原始字符 |

## 📂 支持的文件格式

- **输入**：`.xlsx`（推荐）、`.xls`（需安装 `xlrd`）
- **输出**：`.vcf`（vCard 3.0 标准）

## 🧠 智能列名映射

程序会自动识别以下列名（中英文均支持，不区分大小写）：

| vCard 字段 | 识别的列名示例 |
|------------|----------------|
| 姓名 | 姓名, 名字, name, 全名, fullname |
| 手机 | 手机, 手机号, mobile, cell, 电话1 |
| 工作电话 | 工作电话, 办公电话, work phone, tel_work |
| 家庭电话 | 家庭电话, 住宅电话, home phone, tel_home |
| 公司 | 公司, 单位, company, organization |
| 职位 | 职位, 职务, title, position |
| 邮箱 | 邮箱, email, 电子邮件, e-mail |
| 备注 | 备注, 说明, note, remark |
| 地址 | 地址, address, 家庭住址 |

> 未匹配的列将被忽略（不写入 VCF）。建议将姓名列放在第一列，可提高兜底识别率。

## ✨ 核心功能详解

### 1. 多值拆分

若一个单元格内包含多个电话号码或邮箱（例如 `13800000000,13900000000`），程序会按常见分隔符（逗号、分号、空格、换行等）自动拆分为多条 `TEL` 或 `EMAIL` 记录。

### 2. 路径自动清洗

从 Windows 安全选项卡、属性窗口复制的路径常夹带不可见字符（如 `U+202A` 左至右嵌入）。程序会自动移除：
- 方向格式字符（U+202A~U+202E）
- 零宽空格（U+200B）
- BOM（U+FEFF）
- ASCII 控制字符

清洗后输出正常路径，避免 `文件不存在` 错误。

### 3. 分批输出

手机通讯录一次性导入大量联系人可能失败。可设置 `-b 200`，将每 200 条记录生成一个独立 `.vcf` 文件（如 `通讯录_part1.vcf`、`通讯录_part2.vcf`），分批导入。

### 4. 电话号码清理

只保留数字、加号、空格、括号、连字符和点号，移除其他非法字符，确保号码格式正确。

## 📱 导入手机的方法

1. 将生成的 `.vcf` 文件通过微信、QQ、邮件发送到手机
2. 在手机上点击文件，选择“联系人”或“通讯录”应用打开
3. 确认导入所有联系人

> 若手机提示“文件无效”，可尝试使用 `-b 100` 缩小分批大小重新转换。

## 🐛 常见问题

### Q1: 提示“文件不存在”，但我输入的路径明明正确？
**A**: 请开启 `--debug` 模式重新运行，检查原始输入中是否包含不可见字符（如 `\u202a`）。程序已内置自动清洗，若仍失败，请手动重新输入路径（不要复制粘贴）。

### Q2: 转换后手机号丢失了前导的 `+86`？
**A**: 程序会保留加号、数字、括号等字符，不会主动删除。请检查原始 Excel 中号码是否以 `+86` 开头。

### Q3: 一个单元格内有多个号码，但只导出了第一个？
**A**: 请确认分隔符是否为程序支持的类型（逗号、分号、空格、换行、制表）。例如使用中文顿号 `、` 也是支持的。

### Q4: 输出文件乱码？
**A**: vCard 文件使用 UTF-8 编码，现代手机均支持。若旧手机出现乱码，可用记事本另存为 ANSI 编码（但会丢失部分特殊字符）。
