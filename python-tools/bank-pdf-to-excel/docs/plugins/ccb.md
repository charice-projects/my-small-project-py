# 建设银行 (ccb.py)

## 一句话
7 列单列带符号表格，三级降级（表格→坐标→文本），序号 1~893 连续。

## probe 信号（用于判断"是否是同类"）
- 【2】有 7 列表格
- 表头：`序号 | 摘要 | 交易日期 | 交易金额 | 账户余额 | 交易地点/附言 | 对方账号与户名`
- 独特词："对方账号与户名" + "交易地点/附言"（这两个同时出现 = 建行对账单）
- 【6】前 2 行含"中国建设银行" + "个人活期账户全部交易明细"

## 与同类插件的差异（核心）
| 对比对象 | 差异 |
|---------|------|
| jiaotong.py | 金额是单列带符号（`+8000`/`-0.01`），不是借贷双列 |
| nongye.py | 有表格结构（extract_tables 可用），不走坐标 |

## 字段映射
| 标准字段 | 来源 | 备注 |
|---------|------|------|
| 交易日期 | `交易日期` | `YYYYMMDD` 转 `YYYY-MM-DD` |
| 星期 | 由日期计算 | **英文** `%A` |
| 摘要 | `摘要` | |
| 交易方向 | 由金额正负判断 | |
| **交易金额** | **`交易金额` 保留原始符号** | **禁止 `abs()`！支出为负** |
| 账户余额 | `账户余额` | `round(2)` |
| 对手信息 | `对方账号与户名` | `账号/户名` 斜杠拼接，保留整段 |
| 附言 | `交易地点/附言` | `***` 掩码保留原样 |

## 🔴 已知坑
1. **不要写 `_deduplicate`**（2026-11 差 7,920，见 README 3.2 禁止 1）
2. **`交易金额` 保留原始符号**，禁止 `abs()`（AI 曾犯错把 `abs` 写进本档案，见 README 坑 7）
3. `detect` 必须两个特征词同时命中，不要用 `or` 连宽泛条件（见 README 坑 8）
4. 三级降级阈值用 `< 1` 而不是 `< 5`（避免小 PDF 误触发坐标回退）
