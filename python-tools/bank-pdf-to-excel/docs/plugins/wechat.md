# 微信支付 (wechat.py)

## 一句话
表格提取 + 文本回退 + OCR 降级，三级降级机制。

## probe 信号（用于判断"是否是同类"）
- 【6】前 2 行含"微信支付交易明细证明"（**完整专属标题**）
- 表头通常含"交易单号 | 交易时间 | 交易类型"

## 检测规则
```python
# ✅ 严格：完整专属标题
return "微信支付交易明细证明" in text
```

**这个检测是严格的范本**（alipay/nongye 之前的问题就是没学它）。

## 字段映射
| 标准字段 | 来源 |
|---------|------|
| 交易日期 | `交易时间` |
| 星期 | 由日期计算 |
| 交易单号 | `交易单号`（特色） |
| 交易类型 | `交易类型`（特色） |
| 交易方式 | `交易方式`（特色） |
| 交易金额 | `金额` |
| 交易方向 | `收/支` 列 |
| 对方 | `交易对方`（非标准 `对手信息`） |
| 商户单号 | `商户单号`（特色） |

## 三级降级
1. 主解析：`extract_tables()`
2. 文本回退：`_parse_from_text_fallback()`
3. OCR 降级：Tesseract（需手动安装）

## 🔴 已知坑
1. **OCR 依赖需用户手动安装**（Tesseract + chi_sim 语言包）
2. 文本回退用 20 位数字交易单号做记录分割
3. `detect` 严格（无需修改，是范本）

## 回归校验
- 交易笔数：与 PDF 汇总一致
- 总支出：与 PDF 汇总一致

## 实现要点
- 不继承 `BasePDFParser`（有自己的降级链）
- 详见 `plugins/wechat.py` v2.1
