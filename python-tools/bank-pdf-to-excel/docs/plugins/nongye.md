# 农业银行 (nongye.py)

## 一句话
坐标聚类·逐行，字段名是历史遗留（`交易摘要`/`本次余额`），v18.4 补齐 `交易方向`/`交易分类`。

## probe 信号（用于判断"是否是同类"）
- 【2】extract_tables 返回空
- 【4】行间距稳定 10~25
- 【5】单笔不跨行（top 极差 ≤ 8）
- 【6】前 2 行含"中国农业银行" + "账户活期交易明细清单"

## 🔴 已知坑
1. **不要写 `_deduplicate`**（农行有"同日多笔短信费 -2"，v18.4 已删，见 README 3.2 禁止 1）
2. **字段名是历史遗留**：`交易摘要`（标准是`摘要`）、`本次余额`（标准是`账户余额`）。**新插件不要模仿**
3. `detect` 必须两特征："中国农业银行" + "账户活期交易明细清单"，不要用 `or "农业银行"`（见 README 坑 8）

## 回归校验
- 交易笔数：与 PDF 汇总一致
- `交易方向`/`交易分类` 列非空（v18.4 修复）
- 余额连续性：0 断点
