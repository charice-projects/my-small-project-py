# 招商银行 (zhaoshang.py)

## 一句话
行文本正则，无固定列宽，数据行格式 `日期 CNY 金额 余额 摘要 对手信息`。

## probe 信号（用于判断"是否是同类"）
- 【2】extract_tables 返回空
- 【3】表头无稳定列边界（x0 差异大）
- 【6】前 2 行含"招商银行交易流水"或"Transaction Statement of China Merchant"

## 与同类插件的差异
| 对比对象 | 差异 |
|---------|------|
| nongye.py | 有固定列宽；招行是流式文本，无固定列 |

## 字段映射
| 标准字段 | 来源 |
|---------|------|
| 交易日期 | 正则 `YYYY-MM-DD` |
| 星期 | 由日期计算 |
| 交易方向 | 金额正负 |
| 交易金额 | `CNY` 后面的金额 |
| 账户余额 | `CNY` 后面的余额 |
| 摘要 | 交易类型关键词（`TRANSACTION_TYPES`） |
| 对手信息 | 剩余文本（多级优先级分离，见下） |
| 交易分类 | `classify()` |

## 对手信息分离策略（按优先级）
1. 非人名关键词（如"美团平台商户"）— 维护 `COUNTERPARTY_KEYWORDS` 列表
2. URL（`https?://...`）
3. 中文名（2~30 字符）+ 账号
4. 纯中文名
5. 纯账号（10~20 位数字）
6. "微信转账" 等特定模式

## 对手信息分离示例
| 原始文本 | 摘要 | 对手信息 |
|---------|------|---------|
| `快捷支付 美团平台商户 246494750` | 快捷支付 | 美团平台商户 246494750 |
| `银联快捷支付 江西九江科技中等专业学校 2088...` | 银联快捷支付 | 江西九江科技中等专业学校 2088... |
| `快捷支付 https://www.apple.com/... 1481605881` | 快捷支付 | https://www.apple.com/... 1481605881 |

## 🔴 已知坑
1. **维护 `COUNTERPARTY_KEYWORDS` 列表**（新出现的非人名对手）
2. **行指纹防重复**：多页 PDF 可能有重复行（`_processed_fingerprints` 集合）

## 回归校验
- 交易笔数：与 PDF 汇总一致
- 无重复交易

## 实现要点
- 不继承 `BasePDFParser`（纯文本正则不需要基类）
- 详见 `plugins/zhaoshang.py` v5.5
