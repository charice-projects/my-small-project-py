# 赣州银行 (ganzhou.py)

## 一句话
8 列无边框表格，**单笔交易跨多行**（对手信息/余额换行），用锚点法解析。

## probe 信号（用于判断"是否是同类"）
- 【2】extract_tables 返回空
- 【3】表头 8 列：`交易日期 | 币种 | 交易金额 | 余额 | 交易摘要 | 对手信息 | 收单机构 | 收支类型`
- 【4】行间距稳定 19~20，但…
- 【5】**单笔交易跨 4~5 行**（top 极差 > 8）
- 【6】前 2 行含"赣州银行" + "历史交易"

## 与同类插件的差异
| 对比对象 | 差异 |
|---------|------|
| nongye.py | 逐行解析（一笔一行）；赣州一笔跨多行，必须锚点法 |
| ccb.py | 有表格结构；赣州无表格 |

## 核心算法：锚点法
1. 用表头词的 x0 确定列边界（比 DBSCAN 更稳）
2. 日期列里的 `YYYY-MM-DD` 词作交易锚点（一笔一个）
3. 每个词按"最近锚点"归属（**距离相等时优先上方**）
4. 每列内按 y 排序拼接（余额列直接拼、中文相邻不加空格）

## 关键点：为什么"距离相等时优先上方"
top=190.2 综合收单待清算 ← 溢出行（属于 2025-11-04 这笔）
top=194.7 8321.3 ← 溢出行
top=199.2 2025-11-04 +8000.00 ← 锚点
top=203.7 00079 ← 溢出行（到上一锚点/下一锚点距离均为 4.5）


`00079` 到本笔锚点距离 = 到下一笔锚点距离 = 4.5，相等时若优先下方会被错分。**必须优先上方**。

`if dist < best_dist:`（**严格小于**，不是 `<=`）

## 🔴 已知坑
1. **单笔跨行用锚点法，不是逐行**（见 README 3.2 禁止 5）
2. **`_is_wide_char` 要精确判断 CJK**（`ord(ch) > 127` 会漏判全角标点）
3. **余额列直接拼接**（`8321.3` + `8` → `8321.38`）
4. **中文相邻不加空格**（`南昌大学第二附` + `属医院` → `南昌大学第二附属医院`）
5. `detect` 用 `"赣州银行" in text`（"赣州银行"是特定名称，暂可接受；未来可加"历史交易"）
