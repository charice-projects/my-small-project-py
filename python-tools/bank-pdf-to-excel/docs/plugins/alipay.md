# 支付宝 (alipay.py)

## 一句话
表格提取 + 文本回退，检测"支付宝支付科技有限公司交易流水证明"。

## probe 信号（用于判断"是否是同类"）
- 【6】前 2 行含"支付宝支付科技有限公司" + "交易流水证明"
- 正文含"兹证明"
- 表头通常含"交易时间 | 交易对方 | 金额"

## ⚠️ 关键检测规则（2026-11 v1.2 修复）
**必须是"标题 + 辅助特征"同时命中，不能只用 `or "支付宝"`**：


# ❌ 错误：or 后面宽泛条件让严格条件失效（历史 bug）
return "支付宝支付科技有限公司 交易流水证明" in text or "支付宝" in text

# ✅ 正确：两个特征词 and 同时命中
return "支付宝" in text and "交易流水证明" in text and "兹证明" in text


**原因**：赣州银行流水里出现"支付宝信贷业务"、"支付宝-魏娇"等字样，用 `or "支付宝"` 会被误命中，导致自动检测走错插件。

## 字段映射
| 标准字段 | 来源 |
|---------|------|
| 交易日期 | `交易时间` |
| 星期 | 由日期计算 |
| 交易方向 | `收/支` 列 |
| 交易金额 | `金额`（带符号） |
| **`交易对方`** | `交易对方`（非标准 `对手信息`） |
| 商品说明 | `商品说明`（特色） |
| 付款方式 | `收/付款方式`（特色） |
| 交易订单号 | `交易订单号`（特色） |
| 商家订单号 | `商家订单号`（特色） |
| 摘要 | `商品说明 + 付款方式` 拼接 |
| 交易分类 | `classify_transaction()` |

## 回归校验
- 交易笔数：与 PDF 汇总一致
- 总支出：与 PDF 汇总一致
- 余额连续性：支付宝 PDF 通常无余额列，跳过此项
